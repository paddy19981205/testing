FIX PROMPTS23 / 25

常見問題與修正 Prompt

遇到問題時，不要重做整支影片；先把問題翻成 Codex 能修改的指令。

畫面像簡報

症狀：只有文字卡、沒有狀態推進

補上每 3–5 秒的 visual beat，讓畫面有操作感。

請檢查每一幕是否有 visual beat；太靜態的 scene 加入 state transition 和 motion。

元素跑版

症狀：文字溢出、元件互擋

先查安全邊界與 viewport，再重新分配版面。

請檢查文字溢出、元件遮擋、viewport 超出與安全邊界。

風格不一致

症狀：每頁像不同模板

回到 DESIGN.md，統一顏色、字級、元件與 motion。

請根據 DESIGN.md 統一顏色、字體層級、元件樣式與 motion 規則。

資訊太多

症狀：一頁塞太多段落

把長文改成主標、短句、狀態標籤與畫面提示。

請減少單頁文字，每一幕只保留一個主標與兩個短句。
